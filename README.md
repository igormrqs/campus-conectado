# Campus Conectado

MVP acadêmico Expo/React Native. Identidade: Caderno em Movimento.
Dados iniciais simulados; persistência somente local. Sem backend ou login.

```powershell
npm ci --ignore-scripts
npx tsc --noEmit
npx expo start
```

Abra com Expo Go compatível com SDK 58. Veja docs/ENVIRONMENT.md e
docs/DEMO_SCENARIO.md. Este commit contém o esqueleto; implementação será
integrada após entrega dos dois workers. Ainda não testado em aparelho.
